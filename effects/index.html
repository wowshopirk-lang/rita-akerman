Магнитная кнопка

Когда курсор рядом, кнопка тянется к нему, а когда уходит — мягко возвращается. Лучше всего на главной кнопке: «Написать», «Записаться», «Купить».

Написать мне

На телефоне курсора нет — там кнопка просто нажимается, ничего не ломается.

HTML

<div class="magnet-zone">
  <a class="magnet" href="#contact">Написать мне</a>
</div>

CSS

.magnet-zone {
  display: inline-block;
  padding: 80px; /* зона, в которой кнопка «чувствует» курсор */
}
.magnet {
  display: inline-block;
  padding: 18px 34px;
  border-radius: 999px;
  background: #6F2CFF;
  color: #fff;
  text-decoration: none;
  transition: transform 0.25s ease-out;
}

JavaScript

document.querySelectorAll('.magnet-zone').forEach((zone) => {
  const button = zone.querySelector('.magnet');

  zone.addEventListener('pointermove', (event) => {
    const box = button.getBoundingClientRect();
    const x = event.clientX - (box.left + box.width / 2);
    const y = event.clientY - (box.top + box.height / 2);
    button.style.transform = `translate(${x * 0.3}px, ${y * 0.3}px)`;
  });

  zone.addEventListener('pointerleave', () => {
    button.style.transform = '';
  });
});

Сила притяжения — число 0.3: больше — тянется сильнее. Размер зоны — padding у .magnet-zone.

HTML

<div class="card reveal">…</div>
<div class="card reveal" style="transition-delay: 0.1s">…</div>
<div class="card reveal" style="transition-delay: 0.2s">…</div>

CSS

.reveal {
  opacity: 0;
  transform: translateY(40px);
  transition: opacity 0.6s ease, transform 0.6s ease;
}
.reveal.visible {
  opacity: 1;
  transform: none;
}

JavaScript

const observer = new IntersectionObserver((entries) => {
  for (const entry of entries) {
    if (entry.isIntersecting) {
      entry.target.classList.add('visible');
      observer.unobserve(entry.target); // показали один раз — больше не следим
    }
  }
}, { threshold: 0.2 });

document.querySelectorAll('.reveal').forEach((el) => observer.observe(el));

threshold: 0.2 — блок появляется, когда видно 20 % его высоты. transition-delay даёт соседям появиться по очереди.

Живой фон

Два мягких пятна цвета медленно плывут за текстом. Только CSS: ни картинок, ни видео, страница не тяжелеет.

WEB DESIGNER · IT CREATORrita akerman

HTML

<section class="glow">
  <h1>Заголовок</h1>
</section>

CSS

.glow {
  position: relative;
  overflow: hidden;
  background: #0B0620;
}
.glow::before,
.glow::after {
  content: "";
  position: absolute;
  width: 60vmax;
  height: 60vmax;
  border-radius: 50%;
  filter: blur(80px);
  opacity: 0.75;
  animation: drift 6s ease-in-out infinite alternate;
}
.glow::before { background: #6F2CFF; top: -20%; left: -10%; }
.glow::after {
  background: #FF7AC6; bottom: -25%; right: -15%;
  animation: drift-back 8s ease-in-out infinite alternate-reverse;
}
.glow > * { position: relative; z-index: 1; } /* текст поверх пятен */

@keyframes drift {
  to { transform: translate(15vmax, 10vmax) scale(1.2); }
}
@keyframes drift-back {
  to { transform: translate(-15vmax, -10vmax) scale(1.2); }
}

/* у кого в системе выключена анимация — фон стоит на месте */
@media (prefers-reduced-motion: reduce) {
  .glow::before, .glow::after { animation: none; }
}

Цвета пятен — background у ::before и ::after. Скорость — 6s и 8s: больше — медленнее.
