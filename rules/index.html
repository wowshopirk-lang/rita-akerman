01

Как это работает

CLAUDE.md — обычный текстовый файл с правилами. Claude Code загружает его в начале каждого чата, поэтому не нужно каждый раз заново объяснять, как вы делаете сайт.

./CLAUDE.mdв папке сайта — правила этого проекта. Самый нужный.
~/.claude/CLAUDE.mdобщий для всех ваших проектов: как вы любите работать.
CLAUDE.local.mdличные заметки к проекту, которые не нужно отдавать другим (добавьте в .gitignore).

Это подсказка для Claude, а не жёсткий запрет: чем конкретнее и короче правила, тем точнее он их выполняет.

02

Шаблон

Скопируйте целиком, сохраните в папке сайта под именем CLAUDE.md и замените примеры на своё. Пример написан для одностраничного сайта студии воздушных шаров.

CLAUDE.md
# Проект
Сайт студии воздушных шаров, одна страница.
Цель — заявки в WhatsApp и через форму.
Аудитория — невесты и организаторы праздников.

# Дизайн
Шрифты: Geologica — заголовки, Inter — текст.
Цвета: фон #FFF8F4, текст #2B1D1A, акцент #E86A92.
Отступы кратны 8px, контент до 1200px.
Сначала мобильная версия, от 375px.

# Код
HTML, CSS и чистый JavaScript, без фреймворков.
Разметка: header, main, section, footer.
У картинок alt, размеры и loading="lazy".
Анимации выключаются при prefers-reduced-motion.

# Проверка
Перед «готово» открой страницу на 375 и 1440px.
Проверь форму, ссылки и консоль браузера.
Не меняй цвета и шрифты без моего согласия.
Без шаблонных блоков «Feature 1, 2, 3».

Если сайт на React, Next.js или Tailwind — напишите это в разделе «Код» вместо «чистого JavaScript», и Claude будет держаться вашего стека.

03

Как писать, чтобы работало

  • Числами, а не словами. «Отступы кратны 8px» вместо «аккуратные отступы». «Акцент #E86A92» вместо «розовый».
  • Одно правило — одна строка. Без «по возможности» и «желательно».
  • Коротко. Держите файл до 200 строк: длинный файл занимает больше места и выполняется хуже.
  • Без противоречий. Если два правила спорят, Claude выберет одно наугад. Перечитывайте файл раз в пару недель.
  • Запреты тоже правила. «Не меняй цвета без спроса» экономит больше всего нервов.
СОВЕТПоправили Claude в чате дважды за одно и то же — допишите это правило в CLAUDE.md, чтобы не повторять в третий раз.
04

Быстрый старт

Если в папке уже есть код, Claude может сам собрать черновик файла. Откройте Claude Code в папке сайта и введите:

/init

Он изучит проект и создаст CLAUDE.md с тем, что нашёл. Если файл уже есть — предложит улучшения, а не перезапишет. После этого допишите разделы «Дизайн» и «Проверка» из шаблона: их Claude сам не угадает.

По материалам официальной документации Claude Code (code.claude.com/docs/en/memory).
