4 плагина Claude Code для сайтов

Чтобы сайт, сделанный с ИИ, не выглядел шаблонно и работал как надо. Все плагины — из официального каталога Anthropic: что делает каждый, как поставить одной командой и как проверить, что работает.

Как ставить

В терминале. Откройте Claude Code в папке сайта (команда claude) и вставьте команду плагина из гайда. Откроется карточка плагина — выберите Install for you, тогда он будет во всех ваших проектах.

В приложении Claude (вкладка Code): кнопка + рядом с полем ввода → Plugins → Add plugin → найдите плагин по названию.

Проверить: команда /plugin → вкладка Installed. Там же плагин можно выключить или удалить.

Каталог claude-plugins-official подключён в Claude Code сразу, добавлять его не нужно.

01 / 04

frontend-design

от Anthropic

Когда вы просите сделать страницу, Claude сам подключает этот навык: выбирает чёткое направление дизайна — шрифты, палитру, анимации — и уходит от шаблонного «нейронного» вида с одинаковыми градиентами.

ПРИМЕР ЗАПРОСАСделай лендинг для пекарни: тёплый, с крупной типографикой и кнопкой «Заказать к 8:00».
/plugin install frontend-design@claude-plugins-official
02 / 04

Playwright

от Microsoft

Даёт Claude браузер. Он сам открывает страницы, кликает, заполняет формы и делает скриншоты, то есть видит, что получилось, а не угадывает по коду.

ПРИМЕР ЗАПРОСАОткрой сайт в браузере, заполни форму записи, проверь, что заявка уходит, и пришли скриншот в ширине телефона.
/plugin install playwright@claude-plugins-official

Нужен Node.js: плагин запускается через npx. Если его нет — скачайте версию LTS с nodejs.org.

03 / 04

Context7

от Upstash

Подтягивает свежую документацию библиотек нужной версии прямо в запрос. Без него Claude может написать по устаревшим примерам: например, подключить Tailwind CSS строками третьей версии, когда стоит уже четвёртая.

ПРИМЕР ЗАПРОСАПодключи Tailwind CSS последней версии, сверься с документацией через Context7.
/plugin install context7@claude-plugins-official

Работает без ключа. Если упрётесь в лимит запросов — ключ можно получить на context7.com и задать переменной CONTEXT7_API_KEY.

04 / 04

security-guidance

от Anthropic

Проверяет код, который пишет Claude, на дыры. Работает в три слоя:

  1. предупреждает прямо во время правок — около 25 опасных приёмов, например текст пользователя в innerHTML или ключ прямо в коде;
  2. в конце каждого ответа разбирает изменения и просит Claude исправить серьёзное;
  3. при git commit проверяет связи между файлами.

Ловит инъекции, XSS, SSRF, ключи в коде, обход авторизации и другое.

/plugin install security-guidance@claude-plugins-official

Разбор идёт на модели Opus и расходует лимиты. Модель можно сменить переменной SECURITY_REVIEW_MODEL. Нужен Python 3.8+ и Claude Code версии 2.1.144 или новее.

БОНУС

claude-code-setup

от Anthropic

Изучает ваш проект и подсказывает, что ещё стоит подключить: хуки, навыки, MCP-серверы.

/plugin install claude-code-setup@claude-plugins-official

Важно

  • Плагины запускают свой код, поэтому ставьте их из официального каталога.
  • Каждый включённый плагин добавляет немного к каждому запросу. Ненужные выключайте в /plugin → Installed.
