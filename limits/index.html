01 / 05

Новая задача — чистый чат

Claude Code отправляет весь разговор с каждым сообщением. Старая история тратит лимит, даже если уже не нужна.

/clear

Чтобы потом вернуться к старому разговору: перед /clear дайте ему имя командой /rename, а вернитесь через /resume.

02 / 05

Длинный чат — сожмите

Если задача та же, но история разрослась, Claude может пересказать её коротко. Можно подсказать, что сохранить.

/compact оставь код и принятые решения

Сжатие само по себе — большой запрос. Если нужна не преемственность, а новый старт, дешевле /clear.

03 / 05

Модель по задаче

Sonnet справляется с большинством задач и стоит меньше. Opus — для сложных решений и многошаговых рассуждений.

/model

Там же можно снизить уровень размышлений для простых задач — команда /effort.

04 / 05

Сначала план, потом код

В режиме плана Claude сначала изучает проект и предлагает подход. Если направление неверное, вы поймёте это до того, как он перепишет полсайта.

Shift+Tab

Пошёл не туда — Escape, чтобы остановить, и /rewind, чтобы откатить разговор и код.

05 / 05

Конкретный запрос

Размытый запрос вроде «улучши сайт» заставляет Claude читать всё подряд. Конкретный — открыть один файл.

добавь проверку телефона в форму в contact.js
БОНУС

Как смотреть, куда уходит лимит

  • /usage — сколько лимита потрачено и что его съедает: навыки, подключения, длинный контекст.
  • /context — что сейчас занимает место в разговоре.
  • /mcp — отключите подключения, которыми не пользуетесь.
  • Файл правил CLAUDE.md держите до 200 строк: он загружается в каждый разговор.
