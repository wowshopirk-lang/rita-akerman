Общая основа

Этот класс нужен всем пяти кнопкам.

.btn {
  position: relative;
  display: inline-block;
  padding: 18px 40px;
  border: 0;
  border-radius: 999px;
  font: 600 18px/1 system-ui, sans-serif;
  text-decoration: none;
  cursor: pointer;
  transition: color 0.3s, transform 0.2s, box-shadow 0.2s;
}
01 / 05

Заливка выезжает слева

Записаться

HTML

<a class="btn btn-fill" href="#">Записаться</a>

CSS

.btn-fill { color: #6F2CFF; box-shadow: inset 0 0 0 2px #6F2CFF; overflow: hidden; isolation: isolate; }
.btn-fill::before {
  content: ""; position: absolute; inset: 0; z-index: -1;
  background: #6F2CFF;
  transform: scaleX(0); transform-origin: left;
  transition: transform 0.35s ease;
}
.btn-fill:hover { color: #fff; }
.btn-fill:hover::before { transform: scaleX(1); }

ВАЖНО

Для тех, кто выключил анимацию

@media (prefers-reduced-motion: reduce) {
  .btn, .btn *, .btn::before, .btn::after { transition: none !important; }
}

На телефоне наведения нет: эффекты срабатывают при касании, кнопки остаются кнопками.
