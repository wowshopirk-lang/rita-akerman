Свой шрифт

Правило: Шрифт под характер бренда: выразительная пара для заголовков и текста.

Своя палитра

ИИ по умолчанию: Фиолетовый градиент на белом фоне
Правило: Один главный цвет и резкий акцент, заданные переменными.

Живой контент

Вставьте перед своей задачей

Сделай первый экран для [бизнес]. Требования к дизайну:
— Шрифты: выразительная пара под характер бренда. Не Inter, Roboto, Arial и не системные.
— Цвет: один главный цвет и резкий акцент, задай их CSS-переменными. Без фиолетовых градиентов на белом.
— Композиция: не «заголовок по центру и три карточки». Крупная типографика, асимметрия, воздух.
— Контент: только настоящие тексты: [вставь тексты]. Без Lorem ipsum и «Feature 1, 2, 3».
— Фон: не плоский цвет — слои градиентов, узор или фактура в духе бренда.
— Движение: одно продуманное появление страницы с задержками у элементов вместо десятка мелких эффектов.
Сделай так, чтобы сайт нельзя было спутать с шаблоном.

Правила опираются на рекомендации Anthropic по фронтенд-дизайну (Claude Cookbooks, «Prompting for frontend aesthetics»).
