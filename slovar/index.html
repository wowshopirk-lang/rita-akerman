Деплой

deploy

Выложить сайт в интернет, чтобы его открыл любой человек по ссылке.

ПРИМЕР«Задеплой на Vercel» — «выложи сайт на хостинг Vercel».
02 / 12

Хостинг

hosting

Сервер, на котором лежат файлы сайта и который круглосуточно отдаёт их посетителям.

ПРИМЕРGitHub Pages, Vercel, Timeweb — это хостинги.
03 / 12

Домен

domain

Адрес сайта, который набирают в браузере. Покупается отдельно от хостинга и продлевается раз в год.

ПРИМЕРmoi-sait.ru — домен.
04 / 12

Репозиторий

repository, repo

Папка проекта, где сохраняется каждая версия кода. Обычно лежит на GitHub.

ПРИМЕР«Закоммить в репо» — «сохрани изменения в истории проекта».
05 / 12

Адаптив

responsive

Сайт сам перестраивается под телефон, планшет и компьютер.

ПРИМЕР«Проверь адаптив» — «посмотри, как сайт выглядит на телефоне».
06 / 12

Фронтенд и бэкенд

frontend, backend

Фронтенд — то, что видит посетитель: вёрстка, кнопки, анимации. Бэкенд — то, что работает на сервере: заявки, база данных, оплата.

ПРИМЕР«Это на бэке» — «это делается на сервере, не в браузере».
07 / 12

API

Application Programming Interface

Способ, которым программы обмениваются данными по правилам.

ПРИМЕРФорма на сайте отправляет заявку в Telegram через API Telegram.
08 / 12

Фреймворк

framework

Готовый каркас, на котором собирают сайт: React, Next.js, Vue, Astro.

ПРИМЕР«Сделай на Next.js» — «собери сайт на этом каркасе».
09 / 12

SSL и HTTPS

SSL, HTTPS

Защищённое соединение: замочек в адресной строке. Без него браузер пишет «Не защищено».

ПРИМЕРНа большинстве хостингов сертификат подключается бесплатно.
10 / 12

SEO

Search Engine Optimization

Всё, чтобы сайт находили в поиске: заголовки страниц, описания, скорость, понятные тексты.

ПРИМЕР«Проверь SEO» — «проверь title, description и скорость».
11 / 12

CMS

Content Management System

Админка, где тексты и фото меняют без кода.

ПРИМЕРWordPress, Strapi — это CMS.
12 / 12

Лендинг

landing page

Сайт из одной страницы под одно действие: записаться, купить, оставить заявку.

ПРИМЕР«Нужен лендинг под акцию» — «одна страница под одну цель».
